# PaperSync

PaperSync — приложение в строке меню macOS. Оно записывает встречи и звонки (Google Meet, Zoom, Microsoft Teams, Jitsi, Slack и другие), расшифровывает их прямо на вашем Mac, подписывает собеседников и запоминает их голоса, а затем делает конспект и список задач. По желанию всё выгружается в Notion.

- **Распознавание речи локальное.** Расшифровку делает Whisper на вашем Mac. Звук никуда не отправляется.
- **В ИИ уходит только текст.** Для конспекта выбранному провайдеру (Anthropic или OpenAI) передаётся текст расшифровки и данные события календаря.
- **Работает само.** Предлагает записать встречу из календаря или звонок, обрабатывает запись после остановки, обновляется без вашего участия.

## Скачать

**[Последняя версия](https://github.com/dimapaperpaperio/papersync-releases/releases/latest)** — файл `.dmg` в разделе Assets.

Требования:
- Mac с Apple Silicon (M1 и новее), macOS 14.4 или новее. Живая расшифровка во время встречи — только на macOS 26 и новее.
- Интернет при первой обработке: PaperSync скачивает модели распознавания (около 1,3 ГБ) и несколько минут готовит их. Дальше всё работает без загрузок.

Обновления приходят сами: раз в сутки приложение проверяет новую версию и устанавливает её. Проверить вручную — «Настройки… → Обновления → Проверить сейчас…».

## Установка и первый запуск

1. Откройте `.dmg` и перетащите PaperSync в «Программы».
2. Запустите приложение из «Программ». В строке меню появится иконка «P». Приложение само включит «Запускать при входе» (переключатель есть в меню).
3. Откроется мастер настройки. Шаги можно проходить в любом порядке, у каждого виден статус. Позже мастер открывается в «Настройки… → Основные → Открыть мастер…».

### Что спросит мастер

- **Ваше имя** — нужно, чтобы отделять ваши задачи от чужих.
- **Разрешения:**
  - **Микрофон** — ваш голос.
  - **Запись системного звука** — голоса собеседников. Без него в записи будете только вы.
  - **Календарь** — для вопроса «Записать встречу?» и подготовки к встречам. Без него запись вручную работает.
  - **Уведомления** — предупреждения о тишине, автостоп, подготовка к встрече, дайджест.
  - **Распознавание речи** — только для живой расшифровки (macOS 26+).

  Если в разрешении отказано, мастер покажет кнопку, которая открывает нужный раздел Системных настроек. Кнопка «Проверить звук» записывает 3 секунды с микрофона и системного звука и показывает уровень.
- **ИИ для конспектов** (рекомендуется; без него будут только расшифровки):

  | Вариант | Что нужно |
  |---|---|
  | Claude (подписка) — по умолчанию | Claude Code и вход: «Войти…» в мастере или `claude /login` в Терминале |
  | ChatGPT (подписка) | Codex: `brew install codex`, затем `codex login` |
  | Anthropic API (ключ) | ключ API, оплата за запросы по тарифам Anthropic |
  | OpenAI API (ключ) | ключ API, оплата за запросы по тарифам OpenAI |

  Есть подписка — берите её: отдельно платить не нужно. Ключи API хранятся в связке ключей macOS. Сменить вариант можно в «Настройки… → ИИ».
- **Notion** (по желанию): создайте внутреннюю интеграцию на notion.so/profile/integrations, подключите её к странице (меню страницы → Connections), вставьте токен в мастере и нажмите «Создать автоматически» — появятся базы «Встречи» и «Задачи». Затем «Проверить подключение» и «Настройки… → Notion → Выгружать встречи в Notion».

## Что умеет

### Запись

- **«Записать встречу?»** Когда начинается встреча из календаря со ссылкой на звонок и микрофон занят другим приложением, PaperSync спрашивает, записывать ли её. Запись начинается только после «Записать».
- **Звонки вне календаря.** Если микрофон 20 секунд занят Zoom, Teams, Slack, Telegram, FaceTime, WhatsApp, Discord, Skype или браузером, появится «Записать звонок?». Запись остановится сама, когда микрофон и звук свободны 2 минуты.
- **Вручную** — меню → «Начать запись» / «Остановить» или F5.
- **Начало не теряется.** Пока висит вопрос «Записать встречу?», звук уже пишется во временную папку. Нажали «Записать» — в запись попадёт всё с момента появления вопроса. Отказались — временный звук удаляется.
- **Пауза** (F6) — на паузе ничего не записывается.
- **Отметки** (F7) — отметить важный момент. В конспекте появится раздел «Отмеченные моменты».
- **Конец встречи.** Когда встреча по расписанию закончилась, PaperSync предложит остановить или продолжить запись, а если сразу начинается следующая — записать её.
- **Автостоп.** Запись, начатая после вопроса «Записать встречу?» или «Записать звонок?», останавливается сама, если микрофон больше никто не использует и 2 минуты нет звука.
- **Тихая запись.** Если через 30 секунд микрофон или системный звук молчат, придёт уведомление — обычно это значит, что не выдано разрешение.
- **Очные встречи.** Если несколько человек говорят в один микрофон, отметьте «Очная встреча» в вопросе или в меню записи — голоса разделятся при обработке. PaperSync умеет определять такие встречи и сам.

### Расшифровка

- **Во время встречи.** PaperSync распознаёт записанное в фоне, поэтому после остановки остаётся обработать только последние минуты. На батарее и под нагрузкой фоновое распознавание приостанавливается.
- **Живая расшифровка** (macOS 26+, F8) — небольшое окно поверх всех окон с репликами «Я» и «Собеседники» почти в реальном времени.
- **Языки** — русский и английский. В режиме «Авто» язык определяется сам («Настройки… → Запись → Язык встреч»).
- **Словарь терминов** — названия и термины, которые Whisper должен узнавать («Настройки… → Запись → Словарь…»). Важные ставьте выше.
- **Обучение по правкам.** Если в окне расшифровки вы заменили неузнанное слово термином, PaperSync предложит добавить его в словарь. Без вашего согласия ничего не добавляется.

### Говорящие

- **Подпись имён.** Собеседники сначала называются «Собеседник-1», «Собеседник-2»… В «Последние встречи» → встреча → «Подписать собеседников…» прослушайте фрагменты и введите имена; подсказки — участники из календаря и знакомые голоса. Расшифровка, конспект, задачи и страница в Notion обновятся.
- **Голосовая память.** С галочкой «запомнить голос» на следующих встречах имя подставится само. Список голосов — «Настройки… → Голоса».

### Результаты

- **Конспект и задачи** готовятся автоматически после каждой встречи. Ход обработки виден в меню в разделе «Обработка».
- **Мои задачи** — меню → «Мои задачи»: открытые задачи со всех встреч, просроченные первыми. «Все задачи…» — окно с поиском и фильтрами. При включённом Notion статус «Готово» синхронизируется в обе стороны.
- **Follow-up** — «Написать follow-up…» готовит письмо участникам: что решили, кто что делает, открытые вопросы. «Открыть в Почте» только открывает черновик, отправляете вы.
- **Дайджест недели** — по пятницам в 17:00 сводка: главное, решения, ваши задачи, задачи других, которых вы ждёте, открытые вопросы. Открыть в любой момент — меню → «Дайджест недели…». День и время меняются в «Настройки… → Основные».
- **Подготовка к встрече** — за 5 минут до встречи из календаря приходит уведомление с прошлыми встречами с теми же участниками и открытыми задачами.
- **Экспорт в Notion** — после каждого конспекта: название, дата, участники, итог, разделы конспекта и задачи. Повторная выгрузка не создаёт дублей.

### Поиск

- **Спросить по встречам…** (F9) — вопрос по прошлым встречам: «что мы решили по баннеру?», «что я обещал Пете?». Период — 7, 30, 90 дней или всё время. Ответ ссылается на дату и название встречи.
- **Spotlight** — обработанные встречи находятся через ⌘Пробел. Индекс только на этом Mac; выключается в «Настройки… → Основные».
- **Окно расшифровки со звуком** — «Открыть расшифровку»: клик по реплике проигрывает звук с этого места, ⌘F — поиск, двойной клик — правка. После правки можно пересобрать конспект.

### Хранение

- **Сжатие** — «Настройки… → Запись → Сжимать записи после обработки»: примерно в 6 раз меньше места, на расшифровку не влияет. Кнопка «Сжать старые записи» сжимает уже сделанные.
- **Автоочистка** — «Настройки… → Запись → Хранить аудио»: всегда, 1, 7, 30 или 90 дней. Аудио старше срока уходит в Корзину; расшифровка, конспект и задачи остаются. После очистки встречу нельзя расшифровать заново.

## Горячие клавиши

Работают в любом приложении.

| Клавиша | Действие |
|---|---|
| F5 | Начать запись; во время записи — остановить (второе нажатие в течение 2,5 с). На вопросе «Записать встречу?» — «Записать», на «Встреча закончилась» — «Остановить» |
| F6 | Пауза / продолжить |
| F7 | Отметить момент |
| F8 | Показать или скрыть живую расшифровку |
| F9 | Спросить по встречам… |
| ⌃⌥N | «Не записывать» или «Продолжить» на вопросе |

Сочетания меняются в «Настройки… → Основные → Горячие клавиши». На MacBook F-клавиши нажимаются вместе с fn, либо включите «Использовать F1, F2 и т. д. как стандартные функциональные клавиши» в Системных настройках → Клавиатура.

## Где хранятся данные

- **Записи встреч** — `~/Documents/PaperSync/`, по папке на встречу: звук, расшифровка, конспект, задачи. Открыть — меню → «Все записи в Finder».
- **Словарь, голоса, модели** — `~/Library/Application Support/PaperSync/`.
- **Дайджесты** — `~/Documents/PaperSync/Дайджесты`.
- **Ключи API** — в связке ключей macOS.

## Приватность

- **Остаётся на Mac:** звук, расшифровка, разделение по говорящим, отпечатки голосов, живая расшифровка, подготовка к встречам.
- **Уходит выбранному провайдеру ИИ** (Anthropic или OpenAI): для конспекта — текст расшифровки и данные события календаря; для «Спросить по встречам…» — конспекты, задачи и часть расшифровок за выбранный период. Звук не отправляется.
- **Уходит в Notion** (если включено): название, дата, участники, итог, разделы конспекта и задачи. Расшифровка, звук и голоса не выгружаются.

## Частые вопросы

**В записи нет голосов собеседников.**
Выдайте разрешение «Запись экрана и системного звука»: Системные настройки → Конфиденциальность и безопасность. Для вашего голоса — раздел «Микрофон». Кнопка «Проверить звук» в мастере покажет, что слышно.

**Первая обработка идёт долго.**
В первый раз PaperSync скачивает около 1,3 ГБ моделей и несколько минут готовит их. Нужен интернет. Это происходит один раз.

**Конспект не сделан, ошибка «Failed to authenticate».**
Истёк вход в Claude: нажмите «Войти…» в мастере или выполните `claude /login`, затем меню → «Обработка» → «Повторить обработку». Для ChatGPT — `codex login`.

**Как обновиться?**
Обновления ставятся сами. Чтобы проверить сейчас — «Настройки… → Обновления → Проверить сейчас…». Можно и скачать новый `.dmg` со [страницы выпусков](https://github.com/dimapaperpaperio/papersync-releases/releases/latest) и заменить приложение в «Программах».

**Приложение закрылось во время записи.**
При следующем запуске в меню «Обработка» появится «Обработать прерванные записи».

**Как сообщить о проблеме?**
Меню → «Сообщить о проблеме…». PaperSync соберёт архив с версией, настройками (без ключей), журналом и отчётами о сбоях — без звука, текстов и имён. Перед сохранением виден список файлов. Приложите архив к [issue](https://github.com/dimapaperpaperio/papersync-releases/issues) в этом репозитории.

Подробная справка есть в самом приложении: меню → «Справка».
